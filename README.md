# Limitless Note

A quiet place to spread notes across an endless desk.

Click empty space to drop a thought. Move cards around. Zoom out when the board gets busy. Each note is Markdown — write it plainly, preview it when you want it dressed up.

Nothing is uploaded. Notes live in this browser, on this device. No account, nobody else can see them. A different phone or a cleared browser will lose them, so save a copy from the menu if a note matters.
